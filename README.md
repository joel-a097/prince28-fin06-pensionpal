
# PensionPal

PensionPal is a backend application designed to help employees understand their Employees' Provident Fund (EPF) records, pension eligibility, and transfer process.

## Project Goal

Help employees who have changed jobs understand their EPF history and pension-related information.

## Technology Stack

- Python 3.11+
- FastAPI
- Pydantic
- uv
- pytest

## Project Structure

```text
src/
└── pensionpal/
    └── __init__.py
```

## Getting Started

Install dependencies:

```bash
uv sync
```

Run the application:

```bash
uv run pensionpal
```
